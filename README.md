# HS English Quiz – Ulysses • Riders to the Sea • Our Casuarina Tree

Interactive quiz app for **WBCHSE Class 12 English Semester 3**.

## Features
- **120+ questions** covering all three texts
- Practice Mode (click any option → instant answer + explanation)
- Exam Mode (20-min timer + live scoring)
- Modern dark UI, fully responsive (mobile + desktop)
- Works offline

## How to use
1. Open `index.html` in any modern browser (Chrome / Edge / Firefox / Safari)
2. Or enable GitHub Pages for a live link

## Texts covered
| Text | Author |
|------|--------|
| **Ulysses** | Alfred, Lord Tennyson |
| **Riders to the Sea** | J.M. Synge |
| **Our Casuarina Tree** | Toru Dutt |

## Question types included
- MCQs
- Assertion-Reason
- Diagram-based
- Rearrangement
- True / False
- Case-based

Made for exam preparation.
